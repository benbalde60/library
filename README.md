Library of Timbuktu

A Goodreads/Letterboxd-inspired book tracking web app built with HTML, CSS, Bootstrap, and vanilla JavaScript.

Users can:

browse featured books
add new books dynamically
track reading progress
showcase favorite reads
interact with a responsive card-based UI
Features
Responsive navigation bar
Hero/banner section
Book showcase cards
Dynamic book creation using JavaScript
DOM manipulation for rendering books
Search bar UI with icon integration
Bootstrap-powered responsive layout
Interactive “Add Book” functionality

CSS3
Vanilla JavaScript
Bootstrap
